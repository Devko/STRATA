      3. Put it on the card

      At your own risk. Neither Enaga nor STRATA is made, supported or endorsed by Sonicware. Before you start: SYSTEM INFO shows BOOT 1.0.17, a second card holds an official SmplTrek.bin from Sonicware, holding HOME (F4) at power-on reaches BOOT MODE, and the unit runs on its adapter without batteries. A hung image leaves the power key dead.

      1. Unzip and copy everything to the root of the SD card. Merge the ENAGA folder if the card has one, replacing the old APP.ENA.
      2. Hold HOME (F4) while switching on, choose SYSTEM UPDATE, and let it finish. This installs Enaga.
      3. Switch on. F1 + POWER opens the Enaga menu, which lists the apps.
      4. Open a starter project: PROJECT, the screen key RIGHT four times (PROJECTS), pick one, OK twice.

      The zip's STRATA-README.txt has the same steps, and the full guide is INSTALL.md. To go back, install an official SmplTrek update the same way.
